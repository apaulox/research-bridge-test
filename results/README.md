# 결과 기록

- `CLAM_*.md`, `EAT75_*.md`, `MUSICDET_*.md`: 이전 실험·제출 보고서.
- `submission_audit/`: 기존 제출물 검사 자료와 코드 사본.
- `*_manifest.json`: 패키지 구성 기록.
- `*_audit.json`, `*_diagnostic.json`: 검사·진단 결과.
- `*_smoke.csv`: 소규모 실행 결과.
- `*.zip.sha256`: 로컬 제출 ZIP 확인용 해시.
- `helios.txt`, `msi.txt`: 기존 저장소 연결 테스트 파일.
- `file_moves.json`: 정리 전 경로와 정리 후 경로의 대응표.

현재 실험 결과는 `aggressive_audio/records/`와
`aggressive_audio/stem_experiment_medium_v1/`에 있습니다.
과거 JSON·CSV 결과 안의 경로는 실행 당시 기록으로 보존했습니다.
